# Локальний симулятор на 20 гравців

Підміняє Firebase (RTDB + Firestore) локальним сервером, щоб ганяти ігри без інтернету й без запису в справжню базу.
Справжня база не чіпається: сторінки отримують заглушку замість firebase-*.js.

```text
cd bots/local-sim
npm install
npx playwright install chromium      # один раз

node server.js                       # сайт + фейкова база на http://127.0.0.1:8787
```

В іншому терміналі:

```text
# усі сторінки по черзі на екрані телефона: JS-помилки, 404, скріншоти → out/smoke
node smoke.js

# 4 «телефони» в браузері + 16 ботів = 20 гравців у «Хто з нас?», 4 хвилини
set BOTS=16& set BOTGAME=whofrom& node mp.js whofrom.html party_whofrom 4 240        (Windows cmd)
BOTS=16 BOTGAME=whofrom node mp.js whofrom.html party_whofrom 4 240                  (bash)

# гра без ботів: 8 «телефонів»
node mp.js mafia.html mafia 8 240
```

`mp.js <сторінка> <ключ гри> <браузерів> <секунд>` — перший браузер стає ведучим і тисне «Почати», решта навмання грають (заповнюють поля, тиснуть кнопки, малюють). Результат у `out/<гра>/`: `result.json` (фази за часом, помилки, кількість записів у базу) і скріншоти ведучого й гостя на кожній зміні фази. `KILL_HOST_AT=30` закриває телефон ведучого на 30-й секунді — перевірка передачі ведучого.

Боти з `bots/run-tests.js` теж працюють проти симулятора: `FIREBASE_DATABASE_URL=http://127.0.0.1:8787/db`.

Обмеження: правила безпеки бази не перевіряються; на слабкому ПК 10+ браузерів одночасно гальмують, тому для 20 гравців — браузери + боти.
